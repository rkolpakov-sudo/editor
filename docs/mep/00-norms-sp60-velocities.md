## Скорость в обслуживаемой зоне (ГОСТ 30494-2011)

- Оптимум: **0,10–0,15 м/с**.
- Допустимо: **до 0,25–0,30 м/с** (категория A, холодный период ≤ 0,25 м/с).

## Шумовой порог

- При скорости **> 5–6 м/с** в магистралях требуется акустическая проверка (расчёт шума от воздуховода).

## Расчётные формулы

- **Скорость воздуха:** `v = Q / (3600 · F)`, где Q — м³/ч, F — площадь сечения, м², v — м/с.
- **Диаметр круглого воздуховода по расходу:** `d = √(4·F/π)`, затем округление до ближайшего ГОСТ-ряда (см. `02-duct-nomenclature-gost.md`).
- **Эквивалентный диаметр прямоугольного** (по расходу/площади): `d_экв = √(4·a·b/π)`.
- **Эквивалентный диаметр прямоугольного** (по сопротивлению): `d_экв = 2·a·b/(a+b)` — используется в аэродинамическом расчёте.

## Как использовать в коде

Все константы таблиц Л.1/Л.2 должны жить в `packages/core/src/mep/constants.ts` как
типизированная структура: `(расход, часыРаботы) → { min: м/с, max: м/с }` для притока и вытяжки отдельно.
