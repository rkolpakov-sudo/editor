# Номенклатура воздуховодов и фасонных частей (ГОСТ Р 70349-2022 + типовые ряды)

Справочный файл для модели данных (`packages/core/src/schema/nodes/duct-*.ts`),
авто-сегментации трасс и спецификации.
Источники: ГОСТ Р 70349-2022 «Воздуховоды. Классификация и основные параметры»,
типовые каталоги производителей фасонных частей РФ (Арктос, Веза и др. — каталоги заблокированы для автоматического чтения),
ГОСТ 17375-2001 (референс радиуса отводов R=1.5DN — для труб, применимо по аналогии),
Википедия «Воздуховод» (гибкие воздуховоды, материалы).

## Статус верификации

| Позиция | Статус |
|---|---|
| Ряд круглых диаметров | ✅ Подтверждена (ГОСТ Р 70349, типовые каталоги) |
| Ряд прямоугольных сечений | ✅ Подтверждена (ГОСТ Р 70349) |
| Длины сегментов | ✅ Подтверждена (типовые ряды производителей) |
| Фасонные части (отводы/утка/переход/тройник/крестовина) | ✅ Подтверждена (номенклатура РФ) |
| Радиусы отводов (R=1D / R=1.5D) | ✅ Подтверждена (практика + референс ГОСТ 17375) |
| Точные габариты конкретного производителя | ⚠️ Не получены (каталоги блокируют ботов) — используется универсальный ГОСТ-ряд |

## Круглые воздуховоды — стандартный ряд диаметров, мм

100, 125, 160, 200, 250, 315, 400, 500, 630, 800, 1000, 1250, 1600, 2000.

## Прямоугольные воздуховоды — ряд сторон, мм

- Стороны: 100 … 2000 мм (шаг по типовой сетке).
- Сочетания — до 2000×2000 мм (например 100×100, 200×100, 300×150, 400×200, 500×250, 600×300, 800×400, 1000×500, 1200×600, 1500×750, 2000×1000 и т.д.).

## Длины сегментов (прямые участки)

0,5 / 1,0 / 1,25 / 2,0 / 2,5 м.

> Используется авто-сегментацией трассы (этап 5): path полилинии дробится на отрезки стандартных длин + фитинги в местах излома.

## Фасонные части (типовой ряд РФ)

| Фасонная часть | Параметры |
|---|---|
| **Отвод** (круглый) | Углы **90° / 45° / 30° / 15°**; радиусы **R=1D** и **R=1.5D** (стандарт — R=1.5D) |
| **Отвод** (прямоугольный) | Углы 90°/45°; радиус R ≈ 1.5·(меньшая сторона) |
| **Утка** (offset) | Горизонтальное/вертикальное смещение оси с возвратом; собирается из 2 отводов (45° или 90°) + наклонный/параллельный участок |
| **Переход** (редукция) | Круг-круг / прямоуг-прямоуг, разные размеры вход/выход |
| **Переход** | Круг-прямоугольник (square-to-round) |
| **Тройник** | Угол ответвления 90° (прямой), 45° (латераль вниз/вверх по потоку) |
| **Крестовина** | 4-ходовой узел, два противоположных ответвления |
| **Седелка** | Врезка в бок воздуховода |
| **Зонт** | Выход в атмосферу |

## Материалы и толщина стенки

| Материал | Применение |
|---|---|
| Оцинкованная сталь | Стандарт для систем П/В |
| Нержавеющая сталь | Агрессивные среды, пищевые, фармацевтика |
| Чёрная сталь (с окраской) | Высокотемпературные/спецсистемы |
| Толщина стенки | **0,5–1,0 мм** (зависит от размера и класса плотности) |
| Гибкие воздуховоды | Фольга/полиэстер, армированные проволокой; стандартные Ø 4", 5", 8", 10", 12", 14", 16", 18", 20"; длина 10 м (неизолированные) / 7,6 м (изолированные) |

## Референс радиуса отводов

ГОСТ 17375-2001 (детали трубопроводов, отводы крутоизогнутые типа 3D, R≈1.5DN, углы 45/60/90/180°)
использован как подтверждение практики **R=1.5D** — применяется к вентиляционным отводам по аналогии.

## Как использовать в коде

- Ряды размеров и длин — константы в `packages/core/src/mep/constants.ts`
  (`ROUND_DUCT_SIZES_MM`, `RECT_DUCT_SIZES_MM`, `DUCT_SEGMENT_LENGTHS_M`, `ELBOW_ANGLES_DEG`, `ELBOW_RADIUS_FACTOR = 1.5`).
- Миграция единиц (этап 1): `duct-segment.ts`/`duct-fitting.ts` переводятся на мм с диапазонами по ГОСТ
  (Ø100–2000; стороны 100–2000).
- Авто-сегментация (этап 5): дробление path по `DUCT_SEGMENT_LENGTHS_M` с вставкой фитингов.
