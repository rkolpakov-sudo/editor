# Трассировка трасс и обвод пересечений приточных (П) и вытяжных (В) трасс

Справочный файл для сервиса автообвода `packages/core/src/mep/bypass.ts`, инструментов прокладки
и спецификации обвода. Основан на изученной практике проектирования ОВиК РФ и зафиксированных
решениях пользователя (голосования).

## Решения пользователя (зафиксированы)

| Аспект | Решение |
|---|---|
| Модель пересечения | **Горизонтальный обвод в плане (утка)**: обе трассы на одной отметке, вытяжная обходит приточную |
| Приоритет трассы | **Приток (П) идёт прямо** (приоритетная); обход строит **вытяжная (В)** |
| Зазор между корпусами | **≥ 50 мм** |
| Инструмент | **Автоопределение пересечений + автопостроение обвода** |
| Номенклатура фиттингов | **Универсальный ряд по ГОСТ-параметрам** (отводы 90°/45° R=1.5D, утка, переход, тройник по ГОСТ Р 70349) |
| Расчёт после обвода | **Пересчёт потерь на обводе** (ξ отводов, длина, переподбор диаметра) |
| Угол утки | **Автовыбор 45°/90°**: по умолчанию 45°; при нехватке места/длины — 90° с подсказкой |
| Маркировка систем | **supply / exhaust / return** (П/В/рециркуляция) |

## Правила трассировки

1. Трассы прокладываются с отступом от перекрытия по проекту (рабочий диапазон 50–150 мм).
2. В плане трассы П и В могут пересекаться; **физического столкновения нет** — вытяжная делает
   горизонтальный обвод (утку) в плане.
3. В месте прохода через стену — гильза + негорючее уплотнение (см. `03-installation-sp73.md`).
4. На противопожарных преградах — противопожарный клапан.
5. Скорости на участках — по СП 60 прил. Л (см. `00-norms-sp60-velocities.md`).

## Геометрия обвода (утка)

- **Сторона обхода**: ⊥ приточной трассе (в плане).
- **Величина смещения**: `смещение = ширина/диаметр приточной + 2 × 50 мм` (зазор с обеих сторон).
- **Угол отводов**: 45° (R=1.5D) по умолчанию; при недостаточной длине участка — 90° (R=1.5D), с подсказкой пользователю.
- **Состав обвода**: 2 отвода + наклонный участок + параллельный участок, возврат на исходную ось.
- Трасса разбивается в точке пересечения на под-участки; результат — цепочка узлов
  `duct-segment` / `duct-fitting` (`fittingType: 'offset'`).

## Расчёт после построения обвода

- Пересчёт длины трассы вытяжного сегмента (включая наклонный/параллельный участки).
- Суммарный коэффициент местного сопротивления обвода: `Σξ = ξ(отвод1) + ξ(отвод2)`.
  ξ отвода зависит от угла и R/D (для 90° R=1.5D типовое ξ ≈ 0.15–0.25; для 45° — меньше; точные
  значения взять из типовой справочной литературы по аэродинамике сетей, пометить источник).
- Потери давления: `ΔP = Σ(R·l + Z)`, `Z = ξ·(ρ·v²/2)`.
- Переподбор диаметра по ГОСТ-ряду (см. `02-duct-nomenclature-gost.md`), если скорость вышла из диапазона СП 60.

## Алгоритм автообвода (сервис `packages/core/src/mep/bypass.ts`)

1. **Обнаружение**: планарная проверка пересечения полилиний сегментов `supply` vs `exhaust` (отрезки, допуск).
2. **Приоритет**: `supply` (П) остаётся прямой; кандидат на обход — `exhaust` (В).
3. **Геометрия**: сторона обхода ⊥ приточной трассе; смещение = ширина приточной + 2×50 мм.
4. **Угол**: 45° по умолчанию; автопереключение на 90° при нехватке длины + подсказка.
5. **Построение**: разбить вытяжной сегмент, вставить отводы (R=1.5D) + наклонный/параллельный участки, вернуть на ось.
6. **Аэродинамика**: пересчёт длины, Σξ, ΔP, переподбор диаметра по ГОСТ-ряду.
7. **Undo/redo**: через командный слой (checkpoint до мутаций).

## Спецификация обвода

В ведомость материалов попадают (по ГОСТ-номенклатуре):

| Позиция | Параметры |
|---|---|
| Воздуховод прямой | Ø/сечение, длина (по ряду 0,5/1,0/1,25/2,0/2,5 м) |
| Отвод 45° (R=1.5D) | Ø/сечение, угол, R |
| Отвод 90° (R=1.5D) | Ø/сечение, угол, R |
| Утка | Ø/сечение, смещение, угол |
| Крепления | Кол-во по шагу из `03-installation-sp73.md` |

## Как использовать в коде

- `packages/core/src/mep/bypass.ts` — чистый сервис (без Three): детекция, геометрия, аэродинамика.
- `duct-fitting.ts` — добавить `fittingType: 'offset'` + поля `offset` (мм), `angle` (45/90), радиус R=1.5D.
- `duct-segment.ts` / `duct-fitting.ts` — `system: 'supply' | 'exhaust' | 'return'`.

## Этап 9 — утка v2 (утверждено)

Уточнения к модели, реализованные в Этапе 9 (см. `PLAN.md`):

| Аспект | v2-правило |
|---|---|
| Вертикальный зазор | Конфликт — только когда корпуса (диаметр/высота) сближаются на < 50 мм. Разнесённые по высоте трассы с достаточным зазором утку не требуют |
| Доступная прямая | `runIn`/`runOut` считаются по коллинеарной прямой через собственные звенья **и** joint-стыки сети (муфты): участок продолжается через стык до первого изгиба/тройника |
| Несколько пересечений | Одна вытяжка может пересекать несколько притоков — планируются **все** утки сразу (последовательность вдоль трассы), применяются одной командой/одним undo-шагом |
| Сторона обхода | Автовыбор: утка открывается в сторону с меньшим «заходом» притока (косые пересечения); явный `options.side` перекрывает авто |
| Позиция S | Центр S центрируется на пересечении; при нехватке длины сдвигается к стороне с большим `runIn/runOut`, оставаясь в пределах параллельного среднего участка |
| ξ отводов | Единый источник — `elbowZeta` в `aerodynamics.ts` (используется уткой и сетевым расчётом потерь) |
