# Воздухообмен помещений (СП 54.13330, жилые здания) + универсальная база

Справочный файл для расчётного движка `packages/core/src/mep/` (модуль воздухообмена по типу помещения).
Источник: СП 54.13330 «Здания жилые многоквартирные» (на docs.cntd.ru: `document/456054198`, СП 54.13330.2016; актуальная редакция СП 54.13330.2022) и Википедия «Вентиляция» (универсальная база для нежилых).

## Статус верификации

| Позиция | Статус |
|---|---|
| Кухня (газовая/электрическая плита) | ✅ Подтверждена (СП 54 + Википедия) |
| Ванная / туалет / совмещённый санузел | ✅ Подтверждена (СП 54 + Википедия) |
| Жилые комнаты (3 м³/ч·м²) | ✅ Подтверждена |
| Офисные/прочие (20/60 м³/ч) | ✅ Подтверждена (Википедия) |

## Нормируемый воздухообмен квартиры (СП 54)

| Помещение | Требование, м³/ч |
|---|---|
| Кухня с газовой плитой (4-конфорочная) | **90** (вытяжка) |
| Кухня с электроплитой | **60** (вытяжка) |
| Ванная комната | **25** (вытяжка) |
| Туалет | **25** (вытяжка) |
| Совмещённый санузел | **50** (вытяжка) |
| Жилые комнаты | **3 м³/ч на 1 м² площади** (приток) |

> Примечание: значения вытяжки — минимальный расход удаляемого воздуха; приток должен компенсировать суммарную вытяжку.

## Универсальная база (общественные и прочие)

| Категория | Требование |
|---|---|
| Офисные, посетители (пребывание ≤ 2 ч) | ≥ **20 м³/ч на человека** |
| Офисные, постоянно находящиеся люди | ≥ **60 м³/ч на человека** |
| Бомбоубежища / защитные сооружения | ≥ **2,5 м³/ч на человека** |

## Связь с типом помещения (spaceCategory)

Поле `spaceCategory` в схеме зоны (`packages/core/src/schema/nodes/zone.ts`) должно принимать
минимум следующие значения (дополняемые):

- `kitchen_gas` → 90 м³/ч
- `kitchen_electric` → 60 м³/ч
- `bath` → 25 м³/ч
- `toilet` → 25 м³/ч
- `combined_wc` → 50 м³/ч
- `living` → 3 м³/ч·м²
- `office_short` → 20 м³/ч/чел
- `office_permanent` → 60 м³/ч/чел
- `public` / `industrial` → по заданию/технологии

## Как использовать в коде

Таблица «тип помещения → норматив» живёт в `packages/core/src/mep/constants.ts`
как `AIR_EXCHANGE_RATES: Record<SpaceCategory, { rate: number; unit: 'm3h' | 'm3h_per_m2' | 'm3h_per_person' }>`.
Инспектор зоны (`quantities-panel.tsx`) показывает чип «N м³/ч» на основе площади/людей и этой таблицы.
