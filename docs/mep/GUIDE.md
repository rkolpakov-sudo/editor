# Гайд пользователя: агент автотрассировки вентиляции

Простыми словами: ты рисуешь на плане комнату, говоришь, что это за помещение
(кухня, жилая и т.д.), ставишь вентиляционную установку и решётки, проводишь
линии-наброски притока и вытяжки — и нажимаешь кнопку **«Трассировка»**.
Программа сама подберёт сечения воздуховодов по нормам (СП 60), поставит
отводы, тройники и утки (обводы при пересечении притока с вытяжкой), поднимет
воздуховоды под потолок и создаст настоящую сеть. Затем можно выгрузить
ведомость материалов и DXF-план.

Весь расчёт — по нажатию кнопки, без фоновой магии: каждое решение видно
в отчёте «Решения трассировки».

---

## 1. Запуск приложения

1. Открой терминал в папке проекта и выполни:
   ```
   bun dev
   ```
2. Дождись сообщения, что редактор поднялся, и открой в браузере:
   ```
   http://localhost:3002
   ```
3. Появится редактор:
   - слева — панель инструментов (Стена, Дверь, MEP и т.д.);
   - сверху — кнопки вида **3D / 2D** и кнопка **«Вентиляция»**;
   - внизу — подсказки активного инструмента.

Рекомендация: для работы с планом переключись в вид **2D** (кнопка сверху) —
так удобнее рисовать комнаты и трассы.

---

## 2. Нарисовать помещение (комнату)

1. Убедись, что выбран инструмент **«Стена»** (иконка Wall, обычно активна
   по умолчанию; внизу подсказка «Set wall start / end»).
2. Кликай по углам комнаты по очереди:
   - первый клик — начало первой стены;
   - каждый следующий клик продолжает стену (стены рисуются цепочкой);
   - **последним кликом вернись в самую первую точку** — комната замкнётся.
3. Когда комната замкнулась, автоматически появится **зона «Room 1»**
   (залитая область) с площадью — это авто-зона помещения.

Подсказки:
- Шаг сетки 0.5 м; привязка к сетке включена по умолчанию.
- Нарисовать комнату точных размеров проще всего по сетке (например,
  4×3 м — 8×6 клеток по 0.5 м).

---

## 3. Задать тип помещения (главное!)

Тип помещения определяет, сколько воздуха нужно комнате и в какую сторону
(приток или вытяжка). Без типа воздуха вентиляция не посчитается.

**Единые характеристики комнаты.** Вся информация о помещении и вентиляции
собрана в одном месте (без разрозненных меню):
- **левый клик** по комнате — обычное выделение: справа открывается
  инспектор помещения со всеми характеристиками;
- **правый клик** по комнате — контекстное меню у курсора с теми же
  характеристиками.

И в инспекторе, и в контекстном меню показано:
- имя (можно изменить прямо там);
- **тип помещения** — выпадающий список категорий по СП 54:
  - **Кухня (газ)** — 90 м³/ч (вытяжка);
  - **Кухня (электр.)** — 60 м³/ч (вытяжка);
  - **Ванная** — 25 м³/ч; **Туалет** — 25 м³/ч; **Совмещённый санузел** — 50 м³/ч;
  - **Жилая комната** — 3 м³/ч на каждый м² (приток);
  - **Офис <2000 ч** — 20 м³/ч на человека; **Офис постоянный** — 60 м³/ч на человека;
  - **Общественное / Промышленное** — по заданию;
- норма воздухообмена, требуемый расход и система (П — приток / В — вытяжка);
- площадь и высота потолка;
- терминалы комнаты и их расходы;
- рекомендация оборудования.

Выбери нужную категорию — имя комнаты обновится автоматически.

Проверка: если открыть панель «Вентиляция», в разделе «Рекомендация
оборудования» сразу появится подсказка под твою комнату (например, для кухни
90 м³/ч — канальный вытяжной вентилятор). Это значит, что расход посчитался.

---

## 4. Поставить установку и решётки/диффузоры

1. Нажми кнопку **MEP** в левой панели — откроется каталог: Duct, Register,
   HVAC Unit и др.
2. **Установка** — кнопка **«HVAC Unit»**:
   - клик по кнопке, затем клик по плану в том месте, где будет стоять
     установка (например, в углу комнаты).
3. **Решётки и диффузоры** — кнопка **«Register»**:
   - клик по кнопке, затем клик по месту установки решётки.
   - Клавиша **M** переключает монтаж: пол / потолок / стена.
4. **Важно: задай правильный тип каждой решётки** (это решает, пойдёт ли через
   неё приток или вытяжка):
   - переключись в инструмент **«Выделение»** (клавиша **V**);
   - кликни по решётке — в инспекторе появится поле типа;
   - выбери:
     - **Решётка вытяжная** (return-grille) — для кухни, ванной, туалета;
     - **Диффузор потолочный** (diffuser) или **Решётка приточная**
       (supply-register) — для жилой комнаты, офиса.

Итог этого шага: у тебя есть установка (одна) и одна или несколько решёток.
Именно к ним агент будет «привязывать» концы трасс.

---

## 5. Нарисовать эскиз трасс (набросок притока и вытяжки)

Это линии-«намерения»: никаких сечений и фитингов выбирать не нужно.

1. В каталоге MEP выбери **«Duct»** (воздуховод).
2. Нажми клавишу **K** — включится **режим «Эскиз»** (рисуются только пунктирные
   линии-наброски).
3. Клавишей **S** выбери систему:
   - **П** — приток (от установки к приточным решёткам/диффузорам);
   - **В** — вытяжка (от вытяжных решёток к установке);
   - **Р** — рециркуляция (если нужна).
4. Кликами ставь точки линии. **Каждый конец линии должен попасть на установку
   или решётку** (в пределах ~0.5 м) — иначе агент скажет «конец не привязан».
5. Закончи линию клавишей **Enter** (или двойным кликом).
6. Нарисуй столько линий, сколько нужно:
   - магистрали от установки к комнатам;
   - линии могут иметь изгибы (кликай несколько точек);
   - **ответвления к решёткам можно не рисовать вручную** — агент подключит
     их сам, если включена авто-привязка (см. раздел 10, «Допуск терминала»).
7. Приток и вытяжка могут **пересекаться** — ничего страшного: на пересечении
   агент сделает утку (обвод вытяжки с зазором 50 мм).

Подсказка: линии П и В лучше вести от установки в разные стороны, чтобы они
не лежали вплотную друг к другу (параллельные П/В рядом агент пометит
предупреждением «разведите по высоте»).

---

## 6. Открыть панель «Вентиляция» и запустить «Трассировку»

1. Нажми кнопку **«Вентиляция»** сверху — справа откроется панель.
2. Найди раздел **«Агент трассировки»** и нажми **«Трассировка»**.

Что произойдёт:
- агент проверит эскиз (комнаты, типы, установку, решётки, привязку концов);
- если всё в порядке — **построит сеть воздуховодов одним шагом** (отменить
  можно Ctrl+Z);
- если есть **блокеры** — покажет их красными (например: «Полилиния №1: конец
  ни к чему не привязан»). Исправь и нажми снова;
- если есть **предупреждения** — покажет их жёлтыми и всё равно построит сеть
  (best-effort).

Сразу после трассировки в секции появится отчёт:
- **«Построено участков: N»**;
- разворачиваемый список **«Решения трассировки»** — все решения агента
  (сечения по СП 60, отводы, утки, баланс П/В).

---

## 7. Посмотреть результат

- **На плане** появятся настоящие воздуховоды: приток — оранжевые, вытяжка —
  зелёные, с маркировкой **П1/В1/Р1**, отметками оси и низа.
- **«Расчёт сети»** (в панели «Вентиляция»): по каждой системе — суммарный
  расход, критический путь и таблица участков (участок → расход → сечение →
  скорость → ΔP).
- **«Спецификация»** (в панели «Вентиляция»): ведомость материалов —
  воздуховоды по размерам ГОСТ, фасонные части (отводы, утки, тройники),
  решётки, крепления, гильзы через стены, масса стали. Кнопки **CSV** и **DXF**
  скачивают файлы.
  - **DXF-план** содержит слои систем (П/В/Р), фитинги по типу, гильзы/клапаны,
    отметки оси/низа и легенду «Системы».
  - **CSV** открывается в Excel (разделитель «;»).

---

## 8. Утка при пересечении притока и вытяжки

- Если приток и вытяжка пересекаются, в разделе **«Автообвод пересечений П/В»**
  появится «1 пересечение готово».
- Нажми **«Обойти»** — вытяжка сделает обвод (утку) с зазором корпусов 50 мм.
- Утка попадает в спецификацию и DXF. После обвода повторных пересечений
  агент не находит.

---

## 9. Повторная трассировка, предупреждения, очистка эскиза

- **Перестроить сеть** — нажми «Трассировка» ещё раз. Сеть перестроится
  полностью; старые узлы будут пересозданы (перед этим панель предупредит:
  «пересоздаст N узлов прошлой сборки»). Ручные правки построенной сети при
  этом теряются — это нормально.
- **Убрать наброски** — кнопка **«Очистить эскиз»** в секции «Агент трассировки»
  (одним шагом, отменяется Ctrl+Z).
- **Отменить всё** — Ctrl+Z; вернуть — Ctrl+Shift+Z.

---

## 10. Предпочтения трассировки (по желанию)

В разделе **«Предпочтения трассировки»** можно настроить, как агент строит сеть
(аналог Routing Preferences в Revit). Настройки применяются при следующей
«Трассировке»:

- **Врезка ответвления** — тройник, седелка или «авто» (автоматически по
  отношению диаметров);
- **Угол врезки** — 45° (меньше потерь) или 90°;
- **Радиус отводов R/D** — 1D, 1.5D (стандарт) или 2D;
- **Метод подбора сечения** — по скорости СП 60 или «равные потери» (укажи
  целевую удельную потерю в Па/м);
- **Допуск терминала, м** — насколько далеко от магистрали агент сам протянет
  ответвление к решётке;
- **Зазор утки, мм** — зазор между корпусами при обводе.

Кнопка **«Сбросить к умолчаниям»** возвращает настройки по умолчанию.

---

## Частые ситуации и что делать

| Ситуация | Что сделать |
|---|---|
| «Начало/конец ни к чему не привязано» | Подвинь конец линии эскиза к установке или решётке (ближе 0.5 м) |
| «Нет эскиза» | Нарисуй линии в режиме «Эскиз» (клавиша K) |
| «Назначьте тип помещения» | Правый клик по зоне → «Тип помещения» → выбери категорию |
| Решётка не получила расход | Проверь её тип: для кухни/ванной — «Решётка вытяжная», для жилой — «Диффузор» или «Решётка приточная» |
| Строится только приток (или только вытяжка) | Комнате вытяжного типа нужна вытяжная решётка, приточного — приточная; у каждой стороны должен быть терминал |
| «Параллельные П/В… разведите по высоте» | Не веди приток и вытяжку вплотную параллельно; разнеси их в плане или по высоте |
| Скорость ниже нормы на маленьких расходах | Минимальный диаметр по ГОСТ — 100 мм; для малых расходов это ожидаемо |

## Горячие клавиши (шпаргалка)

| Клавиша | Действие |
|---|---|
| **K** | Режим «Эскиз» воздуховода вкл/выкл |
| **S** | Система: П (приток) / В (вытяжка) / Р (рециркуляция) |
| **Enter** или двойной клик | Закончить линию эскиза |
| **V** | Инструмент «Выделение» (чтобы смотреть/менять свойства) |
| **M** | Монтаж решётки: пол / потолок / стена |
| **Ctrl+Z / Ctrl+Shift+Z** | Отменить / вернуть |
| **Esc** | Отменить текущее действие / выйти из инструмента |

## Короткий путь (самое главное)

1. `bun dev` → http://localhost:3002 → вид **2D**.
2. Инструмент **«Стена»**: кликами нарисуй замкнутую комнату → появится зона.
3. Правый клик по зоне → **«Тип помещения»** → выбери категорию (кухня/жилая и т.д.).
4. **MEP → HVAC Unit** — поставь установку; **MEP → Register** — поставь решётки
   и задай им тип (вытяжная / приточная / диффузор) в инспекторе.
5. **MEP → Duct**, клавиша **K** (эскиз), **S** — система; кликами нарисуй линии
   притока и вытяжки от установки к решёткам; **Enter** — закончить.
6. Кнопка **«Вентиляция»** → раздел **«Агент трассировки»** → **«Трассировка»**.
7. Смотри результат: сеть на плане, **«Расчёт сети»**, **«Спецификация»**,
   скачивай **CSV** и **DXF**. Пересечения П/В — кнопка **«Обойти»**.
